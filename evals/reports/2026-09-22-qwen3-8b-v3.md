# qwen3-8b：固定输出契约后的对照结果

本机日期 2026-09-22，场景版本 `common-v3`。模型仍为本地 `qwen3-8b`，温度 0、
seed=42，每种条件重复两次。本轮顺序运行自由输出与 JSON Schema 输出两个完整
流程，各 145 次模型调用，合计 **290 次**，另有一次服务能力探测。

原来的问题、期望答案、记忆、训练/验收/测试划分均保持不变。新契约独立声明字段
和类型，未包含正确答案；所有记忆字段在有记忆与无记忆模式中都允许 null。
两组的 fixture、Rust 二进制、runner、契约模块哈希及采样配置已核对一致。

## 结果

每组最终测试为 114 次调用，包含 19 个场景、三种记忆配置及两次重复。

| 指标 | 自由输出 | 契约输出 |
|---|---:|---:|
| 协议合规 | 102/114 | **114/114** |
| 严格任务通过 | 62/114 | **78/114** |
| 协议合规后内容正确 | 62/102 | **78/114** |

逐题、逐记忆配置、逐重复比较：**16 次从失败变为通过，0 次从通过变为失败**。
这组小样本主要用于验证具体问题的修复，不能视为总体任务成功率或统计显著性结论。

下表只比较 `memory` 配置，以减少学习流程变化带来的干扰：

| 场景 | 自由输出 | 契约输出 |
|---|---:|---:|
| 事实更新 | 2/4 | **4/4** |
| 40 条干扰记忆，query 排序，上限 30 | 0/2 | **2/2** |
| 同等干扰，query 排序，上限 64 | 0/2 | **2/2** |
| 同等干扰，关闭 query，上限 30 | 0/2 | **0/2** |
| 偏好、会话恢复、遗忘、隔离 | 各 4/4 | 各 4/4 |
| 原有客服分流题目 | 4/6 | 4/6 |
| 客服普通问题反例 | 4/6 | **6/6** |

此前错误的 `{"deployment_region":"eu-central-1"}` 变为
`{"region":"eu-central-1"}`；错误的 `{"z_deployment_port":17443}` 变为
`{"port":17443}`。字段名问题在本轮得到修复。

关闭 query 导致目标记忆被截掉时，模型仍返回 `{"port":null}`，协议通过、内容
失败；无记忆的端口测试同样失败。这说明契约约束解决了格式，缺失资料仍需要由
记忆检索解决。评分没有通过重命名字段或填入期望值来修正模型答案。

## 学习结果

两个完整流程分别生成并评估自己的候选策略，结果均为 **rejected**，且确认未改变
生效策略。自由输出候选平均增益为 0.166667，但把普通双重验证咨询分到错误队列；
契约输出候选平均增益为 0，把这类正常安全咨询过度提升为 P0。

契约输出候选把“所有安全相关问题 P0、付款问题 P1”概括成规则，仍超出了训练
样例所能支持的范围。固定 JSON 结构不会自动修复这种业务推理问题。需要继续补充
训练中的边界案例，并使用新的独立保留集验证，而不是放宽采用标准。

因为本轮契约模式覆盖训练、提案、验收与最终测试，候选内容和基线输出都可能发生
变化。不能把跨组的学习分数变化单独归因于 JSON 约束解码。本轮 `schema` 同时加入
显式系统契约和服务端约束，尚未隔离这两部分各自的贡献。

## 实现与验证

- 新增 `evals/output_contract.py`，负责显式契约、请求格式与独立校验。
- runner 提供 `--output-contract none|prompt|schema`，默认 none 保持原有调用方式。
  schema 模式使用本机服务支持的 `response_format.json_schema`。
- `protocol_valid` 单独检查字段、类型、枚举和完整生成；只有协议合格的回答才
  评估 `content_correct`。严格任务分数继续用于学习采用判断。
- 客户端不自动重试、修复字段或在服务不支持时降级；原始请求/响应完整保存。
- 校验器支持明确声明的扁平 JSON 对象子集，不宣称实现完整 JSON Schema。
  不支持的契约提前报错，重复 JSON key 及 NaN/Infinity 被拒绝。
- **16 项离线测试通过**，覆盖契约不泄露答案、模式构造、传输 payload、格式与
  内容分别计分、非法 JSON、截断输出及原数据集保持不变。

两个流程总 tokens 分别为 **30,764** 与 **42,940**。显式契约增加了输入开销，
以上数字包含训练和验收，不能理解为单次业务请求成本。此次未改动 Rust/SDK 实现，
未重复运行上一轮已通过的原生集成测试。
