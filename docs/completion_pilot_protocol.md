# 完成约束真实 Kimi 小试（v1，调用前冻结）

## 问题与范围

新完成约束能否减少误报完成，并让模型在收到拒绝反馈后于剩余预算内恢复？使用三个既有构造工作流（deploy、export、handoff），各取 update（正常新策略）和 forget（来源撤回），共六个情境。每例分别运行 `control` 与 `guarded`，共 12 次任务尝试，各一次模型采样。模型调用真实 Kimi API，工具操作真实隔离文件；不是外部真人、独立业务项目或新存储后端研究。旧 v2 结果不修改。

## 对照与完成标准

两组的初始提示、公开文件、来源快照、模型、工具实现、四轮预算与每轮三个操作完全相同。不给模型组别；无历史记忆策略干扰。`read_source` 读取预先冻结的共同来源快照，不测量在线 SDK 检索性能。按种子 20261007 打乱六例，每例交替组别顺序。

同一 `VerifiedSession` 负责工具、回执与预算。`guarded` 仅在该会话接受时结束；`control` 把协议有效的 `done=true` 直接接受，即使验证或工具失败。control 仍用同一会话计算公开验证状态，供反馈和共同判分使用；它不因该状态拒绝完成。除完成声明的接受/终止行为外，两组的工具结果、验证状态和剩余轮数使用相同反馈结构。

共同主要指标是 **correct_completion**：执行器接受了显式完成请求、同一回合符合共同验证条件（当前快照有成功可信检查、本轮无工具或协议错误）、且独立业务 oracle 判定真实产物正确。`false_completion` 是已接受请求但未满足上述条件；预算耗尽未完成不能算成功。另记 artifact-only 正确、公开验证状态、预算耗尽，以及验证通过但未声明完成。

恢复指标：仅 guarded 中确实被拒绝过 `done=true` 的任务计入分母；随后在四轮内达到共同正确完成才计为恢复。分母为零时恢复率未知，而非 100%。不自动补 run、不修文件、不补答、不扩轮。最后一次修改后必须再 run；允许同一回复按顺序 write/run/done=true。

## 调用、冻结与证据

保持现有 `kimi-k2.6`、非思考、JSON object、提供方默认采样参数，最多 1024 输出 tokens/响应。初始提示明确四轮内需要显式完成，以及最后一轮可同时执行 run 和请求完成。每次工具返回后将完成接受状态、公开验证原因和剩余轮数交给模型；隐藏 oracle、逐轮业务判分和组别不进入提示。

准备阶段无 API、无凭据读取，保存全部相关源码、协议、六例、十二份初始输入与各文件 SHA-256。第一次调用前提交代码并记录提交身份。源码、冻结输入或初始项目不匹配即拒绝运行；尝试过的目录拒绝重跑。源码保持不变直到测量与回放完成。

请求串行，开始间隔至少 21 秒；HTTP 429 可对相同请求等待 60 秒重试，最多两次。总计最多 48 个有响应调用、144 次 HTTP 尝试；累计已报告 tokens 达 100,000 后停止后续调用，最后一次可能超过阈值。请求正文最多 64,000 UTF-8 bytes。其他网络/接口异常立即停批，保留已有结果、部分会话和未知费用，不自动恢复付费请求。缺失用量不能记为零。

每个请求前记录 attempt，响应先落盘再执行工具；保存原始回答、实际工具结果、只用于审计的业务判分及最终文件哈希。独立离线审计重建每个初始项目，逐步核对请求上下文、动作、反馈、回合顺序、预算、最终产物、用量和完成状态。发布报告不包含凭据与本机绝对路径。若停批，完整报告入口拒绝发布，另行报告部分证据。

货币数额仅按此前固定参考费率（2026-10-04：输入 ¥6.5/M、输出 ¥27/M，未缓存）估算，不冒充当前账单或最新报价；本次官方价格页未向文本读取器提供具体价格表。实际 reported token 明列，未答请求费用未知。接口非思考配置已核查 [K2.6 官方文档](https://platform.kimi.com/docs/guide/kimi-k2-6-quickstart)；[官方价格入口](https://platform.kimi.com/docs/pricing/chat)与[限速说明](https://platform.kimi.com/docs/pricing/limits)核查日为 2026-10-07。21 秒间隔是本轮保守配置，不推定账户等级。

## 运行与复核

先提交并保持源码干净。以下准备步骤不调用 API；`run` 需要已配置的 `MOONSHOT_API_KEY`，也可加 `--prompt-key` 使用不回显的终端输入。不要把密钥写进参数或文件。

```sh
python evals/run_completion_pilot.py prepare --output data/completion-pilot-2026-10-07
python evals/run_completion_pilot.py run --output data/completion-pilot-2026-10-07
python evals/run_completion_pilot.py audit --output data/completion-pilot-2026-10-07
python evals/run_completion_pilot.py report --output data/completion-pilot-2026-10-07 --report evals/reports/2026-10-07-completion-live-pilot
```

离线回放要求当前受信任源码与冻结哈希匹配；不执行证据包提供的任意代码。公开轨迹包含冻结记录、任务集、请求尝试、回答、工具执行、最终判分及状态。实现可按冻结提交从 Git 取得；本地运行目录另保留逐文件源码副本与最终产物。审计后生成的汇总不是第三方认证或提供方签名。
